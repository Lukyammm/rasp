# Três níveis de maturidade com IA

Verbete da central Dominação IA, seção "Construir com IA sem parecer que foi IA" (versão de 28/09/2026). Cada item saiu de um post; o "nó" é o número do post, com link em Fontes.

Três posts descrevem a mesma escada por caminhos diferentes, e juntos formam a régua mais útil do acervo: o iniciante usa uma ferramenta para tudo, o praticante usa a ferramenta certa por função, e o especialista monta infraestrutura. A versão do nó 51 é a melhor porque descreve comportamento, não só ferramental.

*3 fontes · confiança média*

**Nível 1: improviso**

- Usa o ChatGPT para tudo
- Landing page com os padrões típicos de IA
- Sem skills e sem arquivo markdown guiando o modelo
- Não ativa o modo de planejamento antes de pedir uma funcionalidade

**Nível 2: ferramenta certa por função**

- Design system montado e customizado, para a IA não reconstruir a UI do zero
- Skills básicas instaladas (frontend-design, shadcn)
- Pede o plano, lê o plano, e só então manda executar
- Ferramenta por função: Claude para pensar, Gemini para contexto longo, NotebookLM para os próprios documentos, ElevenLabs para voz, Claude Code no terminal, Replit para apps

**Nível 3: infraestrutura**

- Skills avançadas e plugin de revisão de segurança
- Skills oficiais de cada tecnologia adotada no projeto
- Busca biblioteca consagrada em vez de mandar reescrever tudo
- Opera MCP para ferramentas, Codex para tarefas, Supabase para dados, Apify para scraping, Clay para leads

**O que não tem aqui.** Nenhum post explica como sair de um nível para o outro; só descreve os níveis.
