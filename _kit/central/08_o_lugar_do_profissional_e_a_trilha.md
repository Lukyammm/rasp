# O lugar do profissional e a trilha

Verbete da central Dominação IA, seção "Construir com IA sem parecer que foi IA" (versão de 28/09/2026). Cada item saiu de um post; o "nó" é o número do post, com link em Fontes.

O contraponto do acervo ao entusiasmo: quem tem repertório usa a IA para acelerar a primeira versão, não para substituir o julgamento. Vem acompanhado da trilha técnica e de uma lista de trocas de ferramenta.

*4 fontes · confiança média*

**Experiência somada à IA**

- Usar a IA para a primeira versão e manter o acompanhamento humano em oferta, design, experiência no celular e revisão
- Não vender rascunho de IA como projeto pronto

**Trilha de desenvolvimento web**

- Front-end: HTML, CSS e JavaScript primeiro; depois React, Vue ou Angular; depois jQuery, Tailwind e Bootstrap
- Back-end: Node.js, Python, PHP, Ruby ou Java; depois MySQL, MongoDB ou PostgreSQL; depois APIs REST e GraphQL

**Dez trocas de ferramenta sugeridas**

- VS Code → Cursor
- GitHub Copilot → Claude Code
- Figma → Penpot
- Busca do Google → Perplexity
- Postman → Bruno
- Heroku → Vercel
- Notion → Obsidian
- ChatGPT → Google AI Studio
- Docker Desktop → Rancher Desktop
- Trello → ClickUp

**Canais para estudar IA por dentro**

- Matemática e estatística: 3Blue1Brown (intuição visual) e StatQuest (base de machine learning e estatística)
- Machine learning e deep learning: Stanford Online, MIT OCW, Caltech, DeepLearning.AI, Jeremy Howard, Michael Bronstein e Steve Brunton
- LLM por dentro: Andrej Karpathy e Umar Jamil
- Prática e projeto: sentdex, Kaggle e Microsoft Developer
- Acompanhar pesquisa: Yannic Kilcher, Two Minute Papers, Arxiv Insights, ML Street Talk, Lex Fridman e Siraj Raval

**Observações.** A lista de trocas do nó 68 é opinião: a própria legenda pondera que cada ferramenta tem seus pontos fortes. O nó 69 é imagem estática sem explicação de ordem nem de profundidade. O nó 65 é post do Threads, a única fonte do acervo fora do Instagram. O nó 141 anuncia canais para dominar IA agêntica, mas a lista é de fundamentos: quase nada ali ensina a construir agente, e nenhum canal é em português.

**O que não tem aqui.** Ninguém justifica as trocas. A trilha do nó 69 lista tecnologias mas não diz quanto tempo nem em que profundidade, e a lista de canais do nó 141 não sugere ordem de estudo.
