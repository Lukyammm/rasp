# Arquivos e pastas

Para organizar pastas, mover, renomear, apagar, fazer backup, trocar de computador, e decidir onde salvar.

## Entrega

- **O que o usuário vai abrir, conferir ou mandar vai numa pasta com o nome do assunto**, não solto. A base e o
  trabalho ficam na pasta do projeto; a pasta de entrega recebe a cópia do que é para ele.
- **Dizer o caminho completo.** Link de arquivo local nem sempre abre: para entrega, oferecer abrir a pasta com o
  arquivo selecionado.
- **Pasta de entrega sem arquivo intermediário** (pedaços, testes, temporários).
- Demanda nova sem pasta definida começa numa pasta com o nome do assunto e depois vai para o lugar certo.

## Organizar sem perder nada

- **Lista antes, ação depois.** Toda organização começa com a lista de cada arquivo, de onde sai e para onde
  vai, e espera o sim. Arquivo que não dá para classificar com segurança fica onde está e entra numa lista de
  dúvidas.
- **Mover, nunca apagar.** Ao mover, gravar um registro (de onde, para onde) que permita desfazer. Nome repetido
  no destino ganha " (2)", nunca sobrescreve.
- **Foto antes de soltar agente ou script na pasta:** `python _kit/scripts/protecao.py fotografar` (da raiz do
  projeto). *Caso:* um agente apagou o bruto de uma coleta com `Remove-Item -Force` ao "organizar".
- **Fonte insubstituível nunca se apaga** (bruto de coleta, manuscrito, respostas de cliente, planilha preenchida
  à mão). Rascunho e derivado podem sair, dizendo o que saiu e por quê.
- **Organizador automático (script ou comando) só roda quando o usuário manda**, deixa um log do que moveu,
  separa trabalho de pessoal, e o que for apagado vai para a lixeira, nunca em definitivo.
- Quando o usuário pede para ficar só a versão nova, as antigas vão para a lixeira e isso se diz.
- Pedido amplo ("passa tudo para o Drive e apaga daqui"): fazer o que é lógico, perguntar o resto, e mesmo com
  autorização não apagar antes de conferir que a cópia chegou ao destino (num disco sincronizado, esperar a
  sincronização terminar).
- Uma pasta com nome de descarte (ex.: `_DESCARTADO`) serve para tirar arquivo do caminho sem apagar.

## Nomes

- **Período e fonte no nome** (ex.: `Clipping_2026-09-16_a_2026-09-30.xlsx`). Uma sessão nova não sabe de que
  período é um arquivo sem isso.
- Backup antes de mudança grande, com motivo e data no nome (ex.: `..._BACKUP_ANTES_RECLASSIFICACAO.pptx`).
- Versão nova não apaga a antiga entregue; a antiga ganha a data ou vai para uma subpasta.

## Downloads

- O que o usuário baixa e tem destino conhecido vai para a pasta certa, com o nome certo, depois de conferido
  (período, colunas, quantidade de linhas), sem sobrescrever.
